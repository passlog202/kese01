## 2. 两个「免浏览器」候选的实测细节

### 2.1 Scraping（京东，纯 requests）

- `jd_monitoring_engine.py`：单文件，`requests + re + lxml`，提供
  `set_searching_url(keyword, page_limit, order)` → `get_basic_info()` 完整链路，
  含评论量、评分、库存、商家等字段提取（比上一轮的 Product-Crawling 更成熟）。
- **实测**：补装 `lxml` 后 `import + 实例化 JDMonitoringEngine()` 成功，无 selenium 硬依赖。
- **问题**：仓库**无 LICENSE 文件** → 不可直接复制作为交付代码，只能「参考思路重写」。

### 2.2 ecommerce-scout（1688，纯 urllib，MIT）

- `src/scrapers/supplier_1688.py`：三策略（suggest API → 搜索页 HTML → 开放 API），
  MIT 协议，`urllib` 实现，零第三方依赖。
- **实测**：
  - ✅ `import` 不触碰 playwright，可独立复用；
  - ✅ `_parse_json_data`（offerList 结构）解析**完全正确**（标题/价/销量/店铺/发货地）；
  - ❌ `_parse_html_block` 有真实 bug：价格正则把「起批5件」里的**5 误当价格**（12.50 被解析成 5.0）。
- **评价**：作为底座可用，但 HTML 解析部分需修复后才能稳定。

## 3. 环境硬边界（为什么沙箱跑不了真机）

- 浏览器：Playwright/chromium CDN、Debian 源均被沙箱阻断，装不了浏览器 → 所有
  selenium/playwright 系底座无法启动。
- 网络：`s.1688.com / www.1688.com / suggest.1688.com / detail.1688.com`、
  `search.jd.com / www.taobao.com` 全部 000（网络隔离）→ 即使纯 requests 也发不出请求。

## 4. 对课设的建议（务实）

1. **课设演示继续用 Mock 数据**（已足够，开箱即跑）。
2. 若要真实数据，**在用户本地/有网络的机器**跑下面任一条：
   - 京东：复用我们自己已写的 `providers/jd.py`（参考 Product-Crawling 思路重写，含幂等入库）；
   - 或移植 ecommerce-scout 的 1688 采集（MIT，可合法使用，但先修掉它的 HTML 价格 bug）。
3. 沙箱内只能做「代码级验证」，真机抓取必须到用户本地环境执行。
