# 真实电商数据源 · 开源爬虫底座评估报告

> 日期：2026-09-23　状态：**已回退 Mock + 采信 Product-Crawling（京东 requests 方案）**
> 背景：拼多多官方开放平台申请流程繁琐（需开发者入驻/应用审核/接口权限审批/HTTPS 备案回调），
> 回退到模拟数据版本后，对开源爬虫底座做了系统化测试，最终选定 **Product-Crawling 的京东
> 纯 requests 实现**作为真实数据源接入（`providers/jd.py`，参考其方案重写，非复制代码）。

## 0. 一句话结论

| 方案 | 是否可用 | 为什么 |
| --- | --- | --- |
| 拼多多官方 API | ✅ 合规稳定，但**申请门槛繁琐**（已实现过，代码留在 `backup-pdd-source` 标签） | 个人开发者可申请，但接口权限、回调地址、审核周期是硬阻塞 |
| **Product-Crawling 京东 requests 版** ★已采用 | ✅ **无需浏览器、无需登录即可尝试**，代码可直接移植 | 京东匿名可搜索，纯 requests 实现，是三个候选里最轻量的真实数据源 |
| 其他爬虫底座（Playwright） | ⚠️ 需真实浏览器 + 目标站点可达 + 扫码登录 | 本地可跑，但受反爬/登录态/改版影响，沙箱内无法验证 |
| Mock 数据（默认） | ✅ 零依赖开箱即跑 | 课设 Demo 唯一不依赖外部的稳定方案 |

## 1. 候选底座测试结果

在沙箱中对三个开源项目做了 clone + 代码级静态测试 + 字段提取离线单测：

### 1.1 shopping-agent-ai（frieren-123/shopping-agent-ai）

- **技术栈**：Python + Playwright + Crawl4AI + Streamlit；MIT
- **平台**：京东 / 淘宝 / 唯品会
- **抓取方式**：`page.on("response")` 拦截 mtop 等 XHR 响应，用正则从 JSON 里抽 `raw_title / view_price / nid / view_sales / nick`
- **适配评估**：字段可直接映射到 `Product`（title→name、view_price→price、nid→external_id、nick→shop）
- **问题**：需有头浏览器扫码登录，是「人机协作」式的半自动流程

### 1.2 Product-Crawling（hairconker/Product-Crawling）★采用

- **技术栈**：Python + Playwright（主力）+ **requests 纯 HTTP 版（京东专用，零浏览器依赖）**
- **平台**：京东 / 闲鱼 / 淘宝（**拼多多已移除**）
- **亮点**：
  - 京东有**纯 requests 实现**（`run_cpu_crawl.py`）：SSR `search.jd.com/Search` + `p.3.cn/prices/mgets`
    价格接口，正则抽 `data-sku`，无需浏览器即可爬京东
  - 极细致的反爬处理：Stealth JS、风控标志识别（`rgv587_flag / deny_h5`）、节流、登录 cookie 自动检测回写
  - 输出统一 `Product` dataclass（platform/item_id/title/current_price/shop_name/image_url…）
- **沙箱实测**：
  - 真机运行（网络阻断）→ 降级健壮：NetworkError → `[FAIL]` → JSON 落盘 → 退出码 1，无崩溃
  - **端到端逻辑测试通过**（本地仿真京东服务器）：命中搜索页 + 价格接口、解析 3 条商品字段完整、
    价格映射正确（含 `-1 无价 → None` 语义）
  - 闲鱼/淘宝在纯 requests 版是「需 cookie + Playwright」的占位实现，不可直接移植
- **注意**：原仓库**无 LICENSE 文件**，故本项目采用「参考其方案重写」（`providers/jd.py`），
  不复制其代码，仅借鉴接口思路（搜索页 SSR 解析 + 价格接口补价）。

### 1.3 JD-Taobao-MCP（HaonanYu123/JD-Taobao-MCP）

- **技术栈**：Python 3.11 + Playwright + MCP server；MIT
- **定位**：human-in-the-loop 的 MCP server（给 AI 工具用），不是独立爬虫库
- **适配评估**：能抽标题/价格/店铺/规格/图片/JSON-LD，但作为 MCP 服务集成成本高于直接封装爬虫；更适合「后续做 AI 购物助手」时接入

## 2. 沙箱实测的网络边界（重要）

在沙箱中实测各站点可达性：

| 目标 | 结果 |
| --- | --- |
| github.com / pypi.org / registry.npmjs.org | ✅ 可达 |
| cdn.playwright.dev / playwright.azureedge.net | ❌ 阻断（浏览器下载失败） |
| search.jd.com / www.jd.com / api.m.jd.com | ❌ 阻断 |
| s.taobao.com / www.taobao.com | ❌ 阻断 |
| gw-api.pinduoduo.com / mobile.yangkeduo.com | ❌ 阻断 |

**结论**：本沙箱对国内电商站点与 Playwright 浏览器 CDN 均不可达，任何真实爬取只能在
**用户本地 / 有网络的服务器**运行；沙箱内只能做「代码级静态测试 + 字段提取离线单测」，
这与「Docker 未安装、只能写配置交付」是同一类环境约束。

## 3. 后续路径（已按此执行）

1. ✅ **京东纯 requests 版**（Product-Crawling 的 `run_cpu_crawl.py`）→ 已移植为 `providers/jd.py`：
   用户本地跑，无需浏览器、无需登录（匿名可尝试，失败需 cookie），最轻量。
2. 淘宝/闲鱼 Playwright 版：需本地装 Playwright + chromium + 扫码登录，脚本式半自动（暂缓）。
3. 拼多多官方 API：合规最稳，但申请链路繁琐，代码留存在 `backup-pdd-source` 标签，答辩加分项。
