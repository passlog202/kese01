# 智能导购系统 · 总体规划

> 项目代号：Smart Shopping Guide
> 版本：V1.0（规划稿，非最终成品）
> 目标：以「食品接触类日用品」为例，构建一个**可持续扩展**的、带**执行标准核验**与**可解释推荐**的智能导购系统。

---

## 1. 项目定位

本系统不是一次性课设成品，而是按照「可后期优化、可新增功能」的架构目标设计：

- **当前**：跑通一条纵向主链路（Mock 商品 → 标准号提取/核验 → 多因素评分 → Top-N 推荐 → 可解释展示）。
- **未来**：可无缝替换数据源（接入京东/淘宝/拼多多爬虫）、加入 OCR、商标识别、评论情感分析、跨平台 SKU 比价、自然语言 LLM 解析等，**核心业务层无需重写**。

## 2. 技术选型

| 层次 | 技术 | 说明 |
| --- | --- | --- |
| 语言 | Python 3.11+ | 后端全项目 |
| Web UI | **Vue 3 + Vite + Element Plus + ECharts** | 美观简洁的现代化前端，纯 HTTP 调用 |
| HTTP 服务 | **FastAPI + Uvicorn** | 契约式后端服务（`/api/v1` + Swagger） |
| 数据处理 | Pandas + NumPy | 商品筛选、统计、评分计算 |
| 智能算法 | scikit-learn | TF-IDF + 余弦相似度 |
| 数据库 | SQLite + 标准库 sqlite3 | 单文件数据库，免部署 |
| 部署 | **Docker + docker compose + nginx** | 前端静态托管 + `/api` 反代 |

**明确不使用**：Django、MySQL、LangChain/LangGraph、深度学习。

## 3. 核心架构

```
              Vue 3 + Element Plus 前端（web/，纯 HTTP 调用）
                          │  /api/v1
             ┌────────────┴────────────┐
             │  HTTP 层 server/        │  FastAPI（schemas/app/service/main）
             └────────────┬────────────┘
             ┌────────────┴────────────┐
             │  业务层 services/        │  recommendation_service
             │                          │  standard_service
             │                          │  product_service
             └────────────┬────────────┘
                          │
             ┌────────────┴────────────┐
             │  算法层 algorithms/      │  similarity（TF-IDF + 余弦）
             │                          │  scoring（多因素加权）
             └────────────┬────────────┘
                          │
             ┌────────────┴────────────┐
             │  数据层 database/ + data │  SQLite / CSV / 标准知识库 JSON
             └─────────────────────────┘
```

### 关键架构原则（后续扩展的核心）

```
真实商城数据
    ↓
ProductSource Adapter（数据源适配器）
    ↓
统一 Product 数据模型  ←—— 无论数据来自 Mock、京东、淘宝、PDD，最终都归一化到这里
    ↓
Normalizer（品牌/价格/标准编号/SKU 归一化）
    ↓
标准识别 + 标准核验
    ↓
ScoringEngine（多因素评分）
    ↓
RecommendationService
    ↓
统一 Response（前后端契约）
    ↓
Vue 3 前端（HTTP）/ FastAPI 契约服务
```

**Demo 阶段使用 `MockProductSource`（即 data/products.csv → SQLite），推荐服务完全不知道数据来源。** 以后新增 `JDProductSource / TaobaoProductSource / PDDProductSource` 只需实现同一导入接口。

## 4. 功能规划

### 4.1 已完成功能（Demo V1）

| 模块 | 功能 |
| --- | --- |
| 商品中心 | 浏览、搜索、按类别筛选；展示执行标准核验状态 |
| 智能导购 | 表单 + 自然语言需求解析；条件过滤 → 相似度 → 标准核验 → 加权评分 → Top-N；可解释推荐理由；评分维度明细 |
| 商品对比 | 同类商品关键参数并排对比，指标最优高亮 |
| 执行标准核验 | 识别 GB / GB·T / QB·T 编号，核对「现行 / 废止 / 未收录 / 未标注 / 无法识别」 |
| 收藏商品 | SQLite 持久化收藏 |
| 推荐历史 | 持久化每次查询与结果，可回看 |
| 数据分析 | 价格分布、品牌/类别排行、评分-价格散点、销量 Top、标准合规统计 |

### 4.2 已完成功能（Demo V2）

在 V1 基础上新增：

| 功能 | 说明 |
| --- | --- |
| Vue 3 前端 | 美观简洁的界面，完全通过 HTTP 契约调用后端 |
| FastAPI 契约服务 | `/api/v1` 全部端点 + Swagger 文档 + CORS |
| 自然语言解析接口 | `/api/v1/parse` 把一句话需求解析为结构化字段 |
| 元数据接口 | `/api/v1/meta` 供前端表单下拉词表 |
| 健康检查 | `/api/v1/health` 供 Docker 探活与前端状态 |
| Docker 部署 | 前端 nginx + 后端 uvicorn 一键编排，数据卷持久化 |
| HTTP 模式历史 | 推荐接口自动持久化历史，供前端回看 |

### 4.3 后续可扩展功能（架构已预留）

- **接入真实商城爬虫**：`shopping-agent-ai`（京东/淘宝/唯品会）、`Product-Crawling`、`pdd` 官方 API、`MarketSpider`（1688）。
- **OCR 识别包装执行标准**：PaddleOCR 提取图片中的 GB/GB·T 编号，交给现有 `standard_service.verify_standard` 核验。
- **标准知识库扩充**：`data/standards/` 下新增 GB/QB 等标准 JSON，`StandardRegistry` 自动加载。
- **自然语言 LLM 解析**：以 LLM 结构化输出替换当前 `core/text_process.py` 规则解析。
- **跨平台同款 SKU 比价**：借鉴 ValuSee 的 SKU 归一化与真实到手价计算。
- **评论情感分析**：在评分维度中增加评论情感分。

## 6. 里程碑

- **M0（已完成）**：技术选型锁定、目录与数据模型确立。
- **M1（已完成）**：Mock 数据 → 标准核验 → 加权推荐 → 可视化完整链路跑通。
- **M2（已完成）**：FastAPI 契约服务，前后端解耦。
- **M3（本版本）**：Vue 3 前端替换 Streamlit，纯 HTTP 调用；Docker 部署配置。
- **M4（可选）**：接入真实爬虫数据源（Adapter）、OCR 包装标准识别、多用户。

## 7. 运行方式

```bash
# 后端
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m server.main             # http://localhost:8000/docs

# 前端
cd web && npm install && npm run dev   # http://localhost:5173（已代理 /api 到 8000）

# 或 Docker 一键启动
docker compose up --build -d      # 前端 http://localhost:8080
```
