# 智能导购系统 · 前后端契约 V3

> 目标：抽象一套稳定的 JSON 契约，**前端（Vue 3 + Element Plus）与后端（FastAPI）解耦**。
> 前端通过 HTTP 调用后端契约服务，契约已在 `server/` 下完整落地，
> 同时保留 `api_contract.py` 供进程内直接调用。
>
> HTTP 根路径前缀：`/api/v1`
>
> **认证**：JWT Bearer Token（HS256）；密码使用 PBKDF2-HMAC-SHA256 哈希存储。
> 除「健康 / 注册 / 登录」外，其余业务端点均需登录。

---

## 0. 运行 HTTP 服务

```bash
# 任选其一
python -m server.main
# 或
.venv/bin/uvicorn server.app:app --host 0.0.0.0 --port 8000
```

- API 文档：http://127.0.0.1:8000/docs （Swagger UI）
- OpenAPI：http://127.0.0.1:8000/openapi.json

### 0.2 统一错误结构

所有 4xx/5xx 响应体使用统一结构：

```json
{
  "api_version": "1.0",
  "ok": false,
  "data": null,
  "error": {
    "code": "INVALID_REQUEST",
    "message": "缺少必要字段 budget_max",
    "field": "budget_max"
  }
}
```

错误码：`INVALID_REQUEST`（参数错误）、`NOT_FOUND`（资源不存在）、`INTERNAL_ERROR`（服务器错误）、
`UNAUTHORIZED`（未登录/凭证无效）、`INVALID_CREDENTIALS`（用户名或密码错误）、`USER_EXISTS`（用户名已存在）。

## 1. 认证接口

### 1.0 统一约定

- 客户端在受保护接口的请求头携带：`Authorization: Bearer <token>`
- token 由注册/登录接口返回，有效期默认 7 天（`KESE_TOKEN_EXPIRE_MINUTES` 可调）。
- 凭证无效时返回 `401` + 错误码 `UNAUTHORIZED`；前端收到 401 会清除本地登录态并跳转登录页。

### 1.1 `POST /api/v1/auth/register`（注册）

**请求体 `RegisterRequest`**

```json
{ "username": "alice", "password": "secret123" }
```

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| username | string | 是 | 3~32 位，字母/数字/下划线/中文 |
| password | string | 是 | 6~64 位 |

**响应 `AuthResponse`**（用户名已存在 → 409 + `USER_EXISTS`）

```json
{
  "api_version": "1.0",
  "ok": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": { "id": 1, "username": "alice" },
    "token_type": "bearer"
  },
  "error": null
}
```

### 1.2 `POST /api/v1/auth/login`（登录）

**请求体**：同注册。错误密码 → 401 + `INVALID_CREDENTIALS`。

### 1.3 `GET /api/v1/auth/me`（当前用户，需登录）

```json
{ "api_version": "1.0", "ok": true, "data": { "id": 1, "username": "alice" }, "error": null }
```

## 2. 智能推荐接口

### 2.1 `GET /api/v1/products`（商品列表）

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| category | string | 否 | 商品类别，如「保鲜盒」 |
| keyword | string | 否 | 名称/品牌/标签关键词 |

**响应**

```json
{
  "api_version": "1.0",
  "ok": true,
  "data": { "count": 44, "items": ["<ProductSummary>..."] },
  "error": null
}
```

### 2.2 `POST /api/v1/recommend`（智能推荐）

**请求体 `RecommendationRequest`**

```json
{
  "category": "保鲜盒",
  "budget_min": 0.0,
  "budget_max": 150.0,
  "preferences": ["防漏", "耐高温", "食品级"],
  "brand": "乐扣乐扣",
  "require_standard": true,
  "top_n": 5
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| category | string 或 null | 否 | null 表示全部类别 |
| budget_min | number | 是 | 预算下限 |
| budget_max | number 或 null | 否 | null 表示不设上限 |
| preferences | string[] | 否 | 偏好标签 |
| brand | string 或 null | 否 | null 表示品牌不限 |
| require_standard | boolean | 否 | true 时仅返回「现行标准」商品 |
| top_n | integer | 否 | 返回数量，默认 10 |

**响应 `RecommendationResponse`**

```json
{
  "api_version": "1.0",
  "ok": true,
  "data": {
    "query": { "category": "保鲜盒", "budget_min": 0.0, "budget_max": 150.0, "preferences": ["防漏"], "brand": null, "require_standard": true },
    "count": 1,
    "items": [
      {
        "product": "<ProductSummary>",
        "score": 64.82,
        "breakdown": {
          "相似度": 70.0,
          "标准核验": 100.0,
          "价格匹配": 85.0,
          "用户评分": 98.0,
          "销量": 24.0,
          "品牌匹配": 60.0,
          "店铺信誉": 100.0
        },
        "reasons": [
          "✓ 执行标准 GB4806.5-2016 为现行标准，安全核验通过",
          "✓ 价格 45.9 元，低于预算上限 69%"
        ],
        "standard_evidence": ["<StandardEvidence>"]
      }
    ]
  },
  "error": null
}
```

### 2.3 数据结构定义

#### ProductSummary（商品摘要）

```json
{
  "id": 1,
  "name": "乐扣乐扣 耐热玻璃保鲜盒 630ml",
  "category": "保鲜盒",
  "brand": "乐扣乐扣",
  "price": 45.9,
  "rating": 4.9,
  "sales": 12000,
  "stock": 320,
  "shop": "乐扣乐扣官方旗舰店",
  "shop_type": "官方旗舰店",
  "material": "高硼硅玻璃",
  "standard_code": "GB 4806.5-2016",
  "standard_status": "现行",
  "tags": ["食品级", "耐高温", "密封", "玻璃", "易清洗"],
  "description": "可微波冷藏两用，四面锁扣密封",
  "source": "seed",
  "url": "https://example.com/item/1",
  "image": "",
  "created_at": "2026-09-01"
}
```

#### StandardEvidence（标准核验证据）

```json
{
  "raw": "GB 4806.5-2016",
  "normalized": "GB4806.5-2016",
  "matched": true,
  "status": "现行",
  "record": {
    "code": "GB 4806.5-2016",
    "name": "食品安全国家标准 玻璃制品",
    "category": "食品安全国家标准",
    "material": "玻璃",
    "status": "现行",
    "publish_year": 2016,
    "implement_year": 2017
  }
}
```

`status` 取值：`现行` / `废止` / `未收录` / `未标注` / `无法识别`。

#### ScoreBreakdown（评分维度明细）

键固定为 7 个维度：`相似度、标准核验、价格匹配、用户评分、销量、品牌匹配、店铺信誉`，值均为 0~100。

## 6. 兼容性约定

1. **字段命名**统一 snake_case，返回中文枚举值（现状/废止等）。
2. **金额**单位统一为「元」，浮点数保留 2 位小数；相似度/评分统一归一化为 0~100。
3. **null 语义**：`category=null` 表示全部、`brand=null` 表示不限、`budget_max=null` 表示不限上限。
4. 前端只依赖本契约中的字段，**不得**依赖后端实现细节（如表结构、排序算法内部值）。
5. 未来新增字段时只做**增量**，保持向后兼容。
